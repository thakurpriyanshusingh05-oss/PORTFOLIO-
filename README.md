## 🤖 Interactive Portfolio Assistant

The portfolio includes an interactive assistant built with JavaScript.

It can provide information about:
- About me
- Education
- Skills
- Projects
- Interests
- Contact information

The assistant uses JavaScript-based keyword matching to respond to user queries.
